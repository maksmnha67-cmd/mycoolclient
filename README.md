# MyCoolClient

Кастомный Fabric-мод для Minecraft **1.16.5**: красивый HUD (в духе Rockstar Client)
+ ClickGUI (в духе Pouch Client).

**Важно:** это НЕ читерский клиент. Здесь нет killaura, ESP, reach, aimbot,
auto-clicker'ов, x-ray и т.п. Только:

- HUD: координаты, FPS, часы, keystrokes, таймеры зелий — вся эта информация
  и так доступна в ванильной игре (F3 / инвентарь), просто оформлена красивее.
- ClickGUI: удобная панель настроек в стиле категорий/тумблеров/слайдеров,
  чтобы включать-выключать HUD-модули и менять их цвет/позицию.
- VISUAL модули (категория `VISUAL` в GUI):
  - **Trail** — цветной след частиц под ногами (обычная ванильная dust-частица,
    только с настраиваемым RGB-цветом через слайдеры). Чистая косметика.
  - **HandVisuals** — стиль анимации взмаха (шире/уже дуга, медленнее/резче)
    и смещение позиции руки/предмета от первого лица. Трогает только рендер
    (MatrixStack), не влияет на attack cooldown, урон или скорость атаки —
    это ванильная игровая логика, которую мод не изменяет.
  - **GhostTarget** → переименован в **TargetHighlight** — партикл-подсветка
    игрока вплотную (используется `crosshairTarget`, дистанция ~3.5 блока
    жёстко зашита, не настраивается). 4 стиля на выбор через кнопку в GUI:
    `SQUARE` (рамка по контуру), `CIRCLE` (кольцо у ног), `GHOST` (случайные
    точки по хитбоксу), `DEVIL` (красные искры + "рожки"). Цвет и плотность
    частиц настраиваются RGB-слайдерами.
  - **ChinaHat** — косметическая конусная шляпа над головой (видна другим
    игрокам так же, как капа), настраиваемый цвет и масштаб.
  - **BlockOutline** — красивая цветная обводка блока в прицеле вместо
    стандартной чёрной. Это тот же самый блок, который ванильная игра и так
    обвела бы — просто цвет/толщина настраиваются.
  - **AngelHalo** — светящееся кольцо-нимб над головой, цвет и масштаб настраиваются.
  - **Wings** — крылья за спиной, 3 стиля (Angel/Demon/Fairy), цвет и масштаб настраиваются.
  - **SelfNametag** (категория HUD) — твой собственный ник в красивой капсуле
    в углу экрана (обычно свой ник не виден без переключения в 3rd person).

**Специально НЕ включено** (по запросу — это уже читы, а не визуал):
ESP любого вида (target/chest/player), отображение HP/брони чужих игроков
через стены или на дистанции, killaura, aimbot, x-ray и т.п.

## Сборка

### Вариант 1 — через GitHub Actions (проще всего, ничего не ставить локально)

1. Создай новый **приватный** репозиторий на GitHub.
2. Залей туда содержимое этой папки (`mycoolclient/`), включая скрытую папку `.github/`:
   ```bash
   cd mycoolclient
   git init
   git add .
   git commit -m "initial"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/ТВОЙ_РЕПО.git
   git push -u origin main
   ```
   Либо просто перетащи файлы через веб-интерфейс GitHub (Add file → Upload files) — не забудь скрытую папку `.github/workflows/build.yml`.
3. Открой вкладку **Actions** в репозитории — сборка запустится сама при пуше (или нажми "Run workflow" вручную).
4. Дождись зелёной галочки (2-5 минут).
5. Зайди в завершённый run → внизу раздел **Artifacts** → скачай **mycoolclient-jar** (это zip с готовым jar внутри).

### Вариант 2 — локально через `build.bat` (Windows)

Нужен JDK 8 (или 16, если используете loom 0.12+) и Gradle wrapper.

```bash
git clone <твой репозиторий>
cd mycoolclient
./gradlew build
```

Собранный `.jar` появится в `build/libs/mycoolclient-1.0.0.jar`.
Кидаешь в папку `mods` рядом с Fabric Loader 1.16.5 (Fabric API обязателен).

## Управление

- **Right Shift** — открыть/закрыть ClickGUI.
- В категории **HUD** можно включать/выключать отдельные элементы.

## Структура проекта

```
src/main/java/com/mycoolclient/
├── MyCoolClient.java          # точка входа мода
├── module/                    # система модулей (без читов)
├── hud/                       # рендер HUD и сами HUD-элементы
├── hud/modules/                # Coords, FPS, Clock, Keystrokes, PotionTimers
├── gui/                       # ClickGUI экран
├── gui/component/             # UI-компоненты (тумблер, слайдер)
└── mixin/                     # хук рендера в InGameHud
```

## Расширение

Чтобы добавить свой HUD-модуль:

1. Создай класс, наследующий `HudModule`, реализуй `getText()` (или переопредели `render()` для кастомной отрисовки).
2. Зарегистрируй его в `ModuleManager.init()`.

Чтобы добавить фичу в GUI без HUD (например, переключение шейдера блоков, кастомный крестик прицела, звуковые уведомления) —
создавай обычный `Module` с категорией `VISUAL` или `MISC` и подключай логику через `onEnable()/onDisable()`.
